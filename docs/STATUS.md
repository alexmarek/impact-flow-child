  `patterns/homepage-*.php` files expose the section variants individually.

  `if-cards-*`, `if-services-editorial`, `if-cta-split`,
  `if-steps-horizontal`, `if-pricing-tiers`, or `if-contact-split`) plus a
  portfolio child modifier. No parent files were changed.

  and bridges WordPress block markup to that presentation. `functions.php`
  loads it in the frontend and registers it as an editor stylesheet.

  provide block-based site chrome matching the design. Page 79's old
  `page-no-title` assignment was removed so the front-page hierarchy is used.
- `tools/2026-09-23-build-homepage.php --apply` regenerates the child variants,
  backs up the previous page once, validates that there are no freeform
  fragments, and updates page 79.
- Verification: 279 registered blocks, zero freeform fragments, zero Custom
  HTML blocks, zero unknown block types; the saved page matches the generated
  pattern and renders without browser console errors.
